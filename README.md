## HTML e CSS
Aula mostrando o basico de HTML e CSS na prática com o codespace do Github.

### Head x Body
O **Head** é a cabeça da página, é onde você coloca coisas que você quer, ou precisam, carregar antes da págnia em sí. O **Body** é a parte da página em sí, onde todas as partes interagiveis vão estar, como: Botões, textos, imagens, links, etc.
